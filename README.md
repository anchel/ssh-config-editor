# ssh-config-editor

an electron app, manage your .ssh/config

When generating an SSH key, the app uses OpenSSH `ssh-keygen` to create an Ed25519 key, as recommended by GitHub. Generated `id_ed25519` keys are available in the `IdentityFile` suggestions. If `~/.ssh/config` does not exist, it is created automatically.
